# RISCV-TinyLLM-Dilithium

A heterogeneous SoC research project integrating a custom RISC-V processor,
a TinyLLM accelerator, and a Dilithium post-quantum cryptography accelerator.

## Overview

This project explores the design and integration of a heterogeneous computing
platform for edge AI and post-quantum cryptography workloads.

The system consists of three main components:

- Custom RISC-V processor
- TinyLLM hardware accelerator
- Dilithium hardware accelerator

## Target Platform

The target platform for the complete project is the VCU118 FPGA board.
The project aims to generate a bitstream, program the board, and demonstrate the integrated SoC on this platform.
